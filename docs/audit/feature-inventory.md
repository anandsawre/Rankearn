# Rankearn Feature Inventory & Traceability Matrix

**Project:** Rankearn — Learning with Earning Platform  
**Baseline Date:** 2026-10-19  
**Source Baseline:** `latest-main.zip`  
**Target Backend:** Supabase (Auth, PostgreSQL, Storage, Edge Functions)  
**Target Clients:** Flutter User App (`apps/user_app`) & Flutter Admin App (`apps/admin_app`) in Monorepo

---

## Traceability Matrix Legend
- **Status Options:**
  - `Not started`: Feature identified in source, migration not yet initiated.
  - `In progress`: Code scaffolded or in transition.
  - `Implemented`: Feature code complete in Flutter / Supabase.
  - `Verified`: Functionality, security RLS, edge cases, and visual parity tested with evidence.
  - `Blocked`: Requires external prerequisite (e.g. live payment keys, SMS gateway).
